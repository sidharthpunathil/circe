Scanning reads the filesystem of whatever machine the registry runs on. This one is hosted, so {{ .Source }} doesn't exist there. Push your skills up from your own machine instead.

One-time setup

skillbuilder login {{ .BaseURL }}

Push one skill

skillbuilder push ~/.claude/skills/my-skill

Or the whole library at once

skillbuilder push ~/.claude/skills

Point it at one skill directory or a directory of them — it works out which. Companion files come along, and existing skills are left alone unless you add --force. Or use GitHub repo and From a code, which both work from anywhere.
